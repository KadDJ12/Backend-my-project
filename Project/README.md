# Система управління навчальним центром (Educational Center Management System)

## Основні можливості системи

1. **Керування користувачами та ролями**:
   - Авторизація за номером телефону за допомогою JWT-токенів (`django-rest-framework-simplejwt`).
   - Два типи користувачів: **Адміністратор** (повний доступ) та **Викладач** (обмежений доступ до власних уроків, студентів та відвідуваності).
   
2. **Мультифілійність**:
   - Робота з кількома філіями одночасно. Предмети, групи, студенти та викладачі прив'язані до конкретних філій.
   
3. **Гнучкий розклад занять**:
   - Створення одноразових занять для окремих студентів або груп.
   - Створення регулярних занять за шаблоном (**LessonTemplate**) з вибором днів тижня у зручному текстовому форматі (наприклад, `Monday, Wednesday`) та автоматичною генерацією занять на заданий період.
   - **Запобігання конфліктам**: автоматична перевірка на наявність накладок у розкладі викладачів та студентів при створенні уроків. Транзакційне створення серій уроків.

4. **Облік відвідуваності (Attendance)**:
   - Викладачі мають можливість відмічати присутність лише тих студентів, які записані на їхні уроки.
   
5. **Абонементи та тарифікація (Subscriptions)**:
   - Створення гнучких тарифних планів (індивідуальні або групові) для філій.
   - Цінові сітки (ціна за одне заняття в залежності від кількості занять на місяць).
   - Прив'язка студентів до тарифних планів.

6. **М'яке видалення (Soft-Delete / Archiving)**:
   - Безпечне архівування філій та предметів замість фізичного видалення з бази даних для запобігання втрати історичних даних.
   - Перевірка обмежень перед архівацією (наприклад, філію не можна архівувати, якщо в ній є активні студенти чи заплановані уроки).

## Стек технологій

- **Мова програмування**: Python 3.13
- **Framework**: Django 6.0.5 + Django REST Framework 3.17.1
- **Автентифікація**: SimpleJWT (JSON Web Tokens)
- **База даних**: PostgreSQL (у Docker) / SQLite (локально)
- **Документація API**: drf-spectacular (OpenAPI 3.0 / Swagger UI)
- **Контейнеризація**: Docker & Docker Compose


## Структура проєкту та опис додатків

Система побудована за модульним принципом:

* **`Users`**: Кастомна модель користувача `CustomUser` (автентифікація за номером телефону замість `username`). Реалізовано розділення прав доступу на основі ролей.
* **`Branches`**: Керування філіями (`Branch`) та предметами (`Subject`). Містить логіку soft-delete.
* **`Students`**: База даних студентів, контактні дані, статус студента.
* **`Groups`**: Об'єднання студентів у групи (`Group`) через проміжну таблицю `GroupMembership`.
* **`Lessons`**: Керування уроками (`Lesson`), відвідуваністю (`Attendance`) та шаблонами розкладу (`LessonTemplate`). Ядро бізнес-логіки та валідації.
* **`Subscriptions`**: Тарифні плани (`SubscriptionPlan`), цінові сітки та абонементи студентів.
